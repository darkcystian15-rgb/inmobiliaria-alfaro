# Revisión de las cuatro referencias del ingeniero

- Cartera abre en Lista compacta; Tarjetas sigue disponible para consultar posiciones. El acceso a posiciones disponibles desde el panel abre Tarjetas.
- Se elimina Atención operativa de Cartera porque repetía los indicadores superiores. Los filtros de actividad continúan disponibles.
- El panel mantiene agenda, bandejas de trabajo, movimientos recientes y accesos rápidos. Se elimina el segundo bloque de métricas que repetía pendientes de las bandejas.
- Registro elimina el cuadro Registro en preparación. Conserva posición, operación, tipo, nombre y dirección; los datos adicionales del propietario siguen siendo opcionales y plegados.
- Seguimiento ordena primero Visitas pendientes, luego Registrar visitas; primero Tasaciones y textos pendientes, luego Registrar tasaciones.
- Liberar inmueble presenta filas compactas con código, posición, identidad, dirección y operación. Registrar salida despliega el formulario existente con validaciones, importes de venta o alquiler y confirmación. Abrir ficha completa permite consultar datos y documentos.
- Se conserva la regla: la tasación pendiente empieza cuando existe una visita realizada. Los inmuebles que esperan visita no cuentan como tasaciones pendientes.
