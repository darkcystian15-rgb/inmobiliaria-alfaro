# Vista previa unificada y edición de datos junto al archivo

«Ver archivo» abre el visor compartido también para PDF de las categorías con editor (minuta, alquiler y estructura de promesa). Ya no se abre una pestaña automáticamente; abrir aparte y descargar siguen disponibles como opciones explícitas del visor.

«Editar datos del archivo» despliega el formulario dentro de la tarjeta del archivo. Permite cambiar nombre, categoría y observación; no modifica el contenido del Word o PDF. Guardar correctamente o cancelar cierra el formulario. Solo se permite editar un archivo a la vez para preservar los cambios pendientes. El botón comunica su estado desplegado mediante aria-expanded.

Verificación: TypeScript correcto; prueba de navegador con API simulada en 375 y 1440 px que comprueba PDF dentro del diálogo, ausencia de pestañas nuevas, formulario dentro de la tarjeta, edición exclusiva y cierre al guardar/cancelar. No se escribieron expedientes reales.
